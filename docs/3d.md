# 3D scenes

`scene3d()` is a layer of your composition that renders real 3D: meshes with depth, perspective
cameras, lights and shadows. It is drawn by its own WebGL2 renderer and composited like any other node,
so you can put 2D graphics above or below it, mask it, filter it or nest it.

```ts
import { composition, scene3d, camera3d, light, plane, box, text3d, layer3d, video, orbit, keys } from 'tasweerix';

export default composition({ width: 1920, height: 1080, fps: 30, duration: 6 }, (c) => {
  c.add(
    scene3d(
      { background: '#0b1020', fog: { color: '#0b1020', near: 8, far: 20 } },
      camera3d({ position: orbit({ radius: 7, height: 2, speed: 12 }), target: [0, 0.5, 0] }),
      light.directional({ position: [4, 6, 3], castShadow: true }),
      plane({ size: [20, 20], rotation: [-90, 0, 0], position: [0, -0.5, 0], color: '#334155' }),
      text3d('تصوير', { font: 'assets/fonts/Cairo-Bold.ttf', size: 1.2, depth: 0.3, color: '#fbbf24', metalness: 0.5 }),
      box({ position: [2, 0, 0], rotation: keys([[0, [0, 0, 0]], [6, [0, 360, 0]]]), color: '#22d3ee' }),
      layer3d(video('assets/clip.mp4', { size: [1920, 1080] }), { position: [-2.5, 1, -1], rotation: [0, 30, 0] }),
    ),
  );
});
```

## Coordinates and timing

- World units, **y up**, right-handed (the camera looks down −Z by default), like three.js and glTF.
- Every 3D object has `position` (Vec3), `rotation` (Euler degrees, applied X then Y then Z), `scale`
  (number or Vec3), `opacity` and `visible`. Children of `group3d()` (and of any mesh) inherit its
  transform.
- Every property is animatable: values, `keys([...])`, or drivers `(f) => …`. `start`, `duration` and
  `end` work as for 2D nodes, so objects can enter and leave.
- The scene itself is a 2D node: `size` (default: the composition size), `at`, `opacity`, filters,
  masks and blend modes apply to the rendered image.

## Objects

| Factory | Geometry props |
| --- | --- |
| `box()` | `size: [w, h, d]` |
| `sphere()` | `radius`, `segments` |
| `plane()` | `size: [w, h]` (faces +Z) |
| `cylinder()` / `cone()` | `radius`, `radiusTop`, `height`, `segments` |
| `torus()` | `radius`, `tube` |
| `extrude(d)` | SVG path data, `depth`, `scale` (world units per path unit, default 0.01), `smoothAngle`. Holes are found by nesting, so any winding works. |
| `text3d(text, { font })` | `size`, `depth`, `align`, `letterSpacing`, `lineHeight`, `direction`. Shaped by HarfBuzz from a font file, with bidi: Arabic letters join correctly. |
| `model(src)` | glTF 2.0 (`.glb`, `.gltf` with embedded or external buffers) and OBJ (+ MTL colors). Node hierarchy, PBR factors, base color textures and vertex colors are imported. |
| `mesh(geometry)` | Your own `{ positions, normals, uvs, indices, colors? }` |
| `layer3d(node)` | A plane showing any 2D node (video, `comp()`, group, text …) rendered every frame: After Effects-style 3D layers. `size` in world units, `mapSize` in pixels. |

Geometry with animated parameters (for example an animated `depth`) is rebuilt only when the values
change and GPU buffers are cached.

## Materials

Mesh props: `color`, `map` (image path, or a node for video and live 2D textures), `metalness`,
`roughness`, `emissive`, `emissiveIntensity`, `opacity`, `transparent`, `unlit` (exact colors, used by
`layer3d`), `doubleSided`, `castShadow`, `receiveShadow`. Shading is a metalness/roughness model
(GGX specular, Lambert diffuse) with gamma-correct color handling. Model files keep their own
materials; node props tint them.

## Lights and cameras

- `light.directional({ position, target, intensity, color, castShadow })` — the first shadow-casting
  directional light renders a PCF-filtered shadow map fitted to the scene (`shadowMapSize` on the scene).
- `light.point({ position, intensity, range })` — up to 8; `light.ambient()` adds to the scene's
  `ambient`/`ambientIntensity`. Without lights, a default key light is used.
- `camera3d({ position, target, fov, near, far, roll, orthographic })` — `target: null` uses the
  camera's own `rotation`. The **last active camera** child is used, so camera cuts are just timing:
  `camera3d({ …, duration: 2 }), camera3d({ …, start: 2 })`. `orbit({ radius, height, speed })` is a
  ready-made position driver.
- Scene options: `background` (null keeps it transparent), `fog: { color, near, far }`, `exposure`,
  `toneMapping: 'aces'`, `samples` (MSAA, default 4).

## Studio, export and plugins

- The studio previews 3D scenes live. 3D objects appear on the timeline and in the inspector (editing
  a Vec3 `position` writes `position: [x, y, z]`); canvas dragging moves the whole `scene3d` layer.
- Exports render through WebGL2 in headless Chromium. Without a GPU this is SwiftShader: correct but
  slower for large shadow maps or many lights.
- `registerModelLoader(ext, loader)` adds model formats; `extrudeGeometry()` and the primitive
  builders are exported for custom meshes.
