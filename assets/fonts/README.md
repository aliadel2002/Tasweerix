# Bundled fonts

- **Cairo** (Regular, Bold) — © The Cairo Project Authors, SIL Open Font License 1.1 (`OFL-Cairo.txt`)
- **Amiri** (Regular) — © The Amiri Project Authors, SIL Open Font License 1.1 (`OFL-Amiri.txt`)

They are included so the Arabic typography examples and tests work offline. Use any TTF/OTF font in
your own projects by passing its path as `font:` to `text()`.
